# Networking Basics #0

## Description
This repository contains solutions and answers for the **Networking basics #0** project at Holberton School. The project serves as an introduction to foundational computer networking concepts, protocols, and architectural models essential for software engineers, system administrators, and cybersecurity specialists.

## Concepts Covered
* **OSI Model:** Understanding the 7-layered conceptual framework of network communication.
* **Network Topologies & Types:** LAN (Local Area Network), WAN (Wide Area Network), and the Internet.
* **Addressing:** MAC addresses, IPv4 vs. IPv6, Public vs. Private IPs, Localhost, and Subnetting.
* **Transport Protocols:** Differences and use cases of TCP (Transmission Control Protocol) and UDP (User Datagram Protocol).
* **Ports & Services:** Common port numbers (SSH, HTTP, HTTPS).
* **Diagnostics & Tools:** Ping, ICMP, and Netstat.
* **Bash Scripting:** Working with positional parameters and writing robust shell scripts.
